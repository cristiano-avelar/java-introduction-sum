# Exercício 1 — Introdução ao Java (Eclipse + GitHub)

Projeto desenvolvido na disciplina **Trabalho Interdisciplinar II: Back-End (PUC Minas)**, com o objetivo de introduzir o uso do ambiente Eclipse e GitHub no desenvolvimento de aplicações Java.

---

## 📌 Objetivo

O objetivo deste exercício é desenvolver um programa simples em Java para somar dois números inteiros, praticando:

- Criação de projeto Java no Eclipse
- Criação de classes
- Compilação e execução de código
- Versionamento com Git e GitHub

---

## 🛠️ Tecnologias Utilizadas

- Java
- Eclipse IDE
- Git e GitHub

---

## ⚙️ Funcionalidade

O programa realiza:

- Entrada de dois números inteiros
- Cálculo da soma
- Exibição do resultado no console
